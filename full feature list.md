# Passhub password manager
## Full featire list

### Type of records:

 - login/passwords with optional:
      - OTP
      - second URL
      - random password generator
 - bank cards
 - addresses
 - files
 - notes

All records have a "notes" field for arbitrary comments 


### Filesystem-like records structure

With folders and sub-folders for easy navigation and sharing. 

### Fine-grained sharing capabiilities

Any top-level folder ("safe") can be shared with unlimited number of users, each user is assigned an owner/editor/read-only acccess rights

### Search 

Search in record titles, usernames, URLs, notes and any fileds but passwords. Search over all records or limit to specific record types (cards/files)
